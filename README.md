# TRADING GUARDIAN
Aplicación educativa para visualizar precios históricos, EMA, RSI, MACD y estimar un riesgo hipotético.

## Ejecutar
`pip install -r requirements.txt`
`streamlit run app.py`

Para usar desde Android, publica `app.py` y `requirements.txt` en un repositorio GitHub y despliega con un servicio compatible con Streamlit. Abre la URL desde Chrome.

La app no ejecuta operaciones. Los datos pueden retrasarse o diferir del bróker. Las señales no garantizan ganancias y la calculadora de riesgo es aproximada. Prueba en demo antes de considerar dinero real.
